- `research-engineer.md` — Research Engineer
- `validation-engineer.md` — Validation Engineer
- `architecture-engineer.md` — Architecture Engineer
- `security-engineer.md` — Security Engineer

- `testing-and-automation-engineer.md` — Testing and Automation Engineer
- `designer-engineer.md` — Designer Engineer
- `sales-engineer.md` — Sales Engineer
- `solutions-engineer.md` — Solutions Engineer
- `customer-success-engineer.md` — Customer Success Engineer
- `product-engineer.md` — Product Engineer
- `compliance-engineer.md` — Compliance Engineer

## Notes
- These files define **job roles**, not personas.
- Each role is structured for direct enterprise-style execution.
- All roles assume a shared Supervisor / CEO / execution authority.
- All roles use concise, neutral, high-signal communication.
